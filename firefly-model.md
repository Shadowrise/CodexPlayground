# Светлячок

`firefly-animated.glb` — самостоятельная модель с анимациями `Sit` (6 секунд) и `Fly` (2 секунды), обе зациклены. Направление взгляда — +Z, вверх — +Y. В модели шесть лапок, усики, подвижные надкрылья и прозрачные крылья с прожилками. Глаза моргают в обоих состояниях.

Предпросмотр: http://127.0.0.1:5173/firefly.html при запущенном сервере игры. В нём можно менять цвет свечения и переключать анимации.

Материал светящегося брюшка называется `Firefly_Glow`, источник света — `Firefly_Light`. GLB использует стандартные расширения `KHR_materials_emissive_strength` и `KHR_lights_punctual`. Видимость светового ореола зависит от поддержки bloom в просмотрщике; само излучение задано в материале модели.

Для Three.js предусмотрен `kirby-game/src/firefly.ts`:

```ts
const firefly = new Firefly(gltf, '#baff55');
scene.add(firefly.object);
firefly.setMode('Fly'); // или 'Sit'
firefly.setGlowColor('#ff77bb');
// В цикле кадров:
firefly.update(dt);
```

Цвет брюшка и света обновляется совместно. Для отдельного светлячка передавайте отдельный экземпляр загруженной сцены.

Пересоздание модели: `node make-firefly.mjs`. Изображение настоящей геометрии в двух позах: `node render-firefly.mjs`.
