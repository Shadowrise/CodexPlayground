# Солнечная полянка на экране загрузки

С 24 октября 2026 года эта иллюстрация заменена зацикленным видео,
записанным из игровых моделей. Текущий вариант описан в
`../menu-backdrop/README.md`. Файл сохранён как предыдущий вариант;
браузер его больше не запрашивает.

Ниже сохранено описание прежней версии от 23 октября.

Фон создан встроенным imagegen по запросу пользователя 23 октября 2026 года.
Точный промпт — в `prompt.txt`. Рабочий файл — `public/images/loading-meadow.webp`
(1672 × 941, около 219 КиБ). PNG оптимизирован в WebP с качеством 88% без
изменения размеров.

В прежней версии изображение подключалось прямо в `index.html` и загружалось
с высоким приоритетом, поэтому не зависит от запуска 3D-сцены. Этот же фон
используется под главным меню и выбором персонажа, пока готовится мир.
Исходные цвета текста, индикатора, кнопки повтора и остальных элементов
интерфейса сохранены. Под статусом остаётся тёмная подложка для читаемости;
разноцветные улыбающиеся Кирби расположены ниже. На телефонах фон заполняет
экран с обрезкой по центру. Переводы и отключение анимации при reduced motion
сохранены.

Мир готовится в фоне, но полный игровой кадр не рисуется до входа игрока.
«На поляну» и загрузка имеющегося сохранения доступны сразу. Если сцена ещё
не готова, запрос входа показывает индикатор на этом же фоне и автоматически
продолжается после подготовки графики. Возврат в меню снова скрывает сцену.
