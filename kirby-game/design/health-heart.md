# Сердечко жизни

Готовая 3D-модель для будущего предмета восстановления: округлое бордово-красное
сердечко с рубиновым градиентом, блестящей глазурью и лёгким собственным свечением.
Презентация использует ту же объёмную дымку, что и фрукты, плюс шесть маленьких
поднимающихся искорок. Новых источников света и текстур нет.
Поверхность цельная: внутренние сечения округлены, чтобы острый кончик контура
не создавал продольный залом. Блики мягкие, без подчёркивания центрального шва.

- Модель: `public/models/health-heart.glb`, около 142 KiB, 5952 треугольника, один меш.
- Просмотр: `/health-heart-preview.html`, доступен также в production-сборке.
- Исходник формы и материала: `src/health-heart-model.ts`.
- Дымка, искорки и покачивание: `src/health-heart.ts`.
- Ширина 1.3 м, высота около 1.17 м, толщина около .574 м; Y вверх, лицевая сторона +Z.
  Поворот и масштаб задаются на `group`, точка крепления — центр предмета.
- GLB самодостаточен, сохраняет материал и emission. Анимированная аналитическая
  дымка — шейдер игры, поэтому подключается отдельно через `HealthHeart`.

```ts
import { HealthHeart } from './health-heart';

const heart = new HealthHeart();
heart.group.scale.setScalar(.45); // Подобрать под размер рук конкретного NPC.
heart.floating = false;
npcHand.add(heart.group);
// В цикле презентации: heart.update(elapsedSeconds).

// После выбивания, сохраняя мировое положение:
scene.attach(heart.group);
heart.floating = true;
heart.spinEnabled = true;

// При подборе/удалении: heart.dispose().
// Общие материалы и буферы при этом остаются живы для других экземпляров.
```

Модель подключена к светлячку в бою Метакнайта. Он держит её передними лапками,
при ударе роняет, и команда сразу получает одну жизнь, в том числе сверх пяти.
Награда синхронизируется общими правилами и сохраняется Worker.
Свечение модели и аддитивной дымки усилено втрое; объём дымки увеличен в 1,6 раза.

Пересобрать GLB: `node --import tsx scripts/make-health-heart.ts`.
Проверка: `node --import tsx --test tests/health-heart-model.test.ts`.
Браузерная проверка при работающем Vite: `node scripts/health-heart-browser.mjs`.
