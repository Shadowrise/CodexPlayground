# ryzhik feather paint

`ryzhik-paint-atlas.png` is the opaque albedo atlas for this native pigeon model. Generated and revised with the built-in image_gen tool, using the previous variant as the edit target and Pidgie as the feather-contrast reference. The original UV layout is preserved.

Ginger plumage over the entire head, neck and body, with a brighter rainbow wash over the ginger neck. There is no white collar. Feather edges have the same gentle contrast as Pidgie.

Rebuild both native models with `npx tsx scripts/make-pigeon-plumages.ts`. The generator preserves Pidgie's geometry, skeleton, morph targets and animations, embeds each atlas, and colours the crest and eyelids to match the head.

Visual check: `node scripts/pigeon-plumages-browser.mjs --textures-only` renders the four native models under identical lighting, plus a closer view of the two new variants.
