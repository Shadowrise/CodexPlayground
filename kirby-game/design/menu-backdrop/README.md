# Живая полянка за меню

Фон записан 24 октября 2026 года из настоящих игровых пресетов, без панелей
и кнопок игрового интерфейса. Яркий день, снежные горы, берёзы и фруктовые
деревья, мельница справа, небесная тропа слева, цветущий луг, речка с лодками.
Шесть крупных Кирби расставлены по краям и внизу; центральная область оставлена
для меню. Нижняя пара видна и при обрезке фона на вертикальном телефоне.
Центральная пара разнесена с зазором на всём Idle-цикле. Светлячок летает
по горизонтальной окружности, его настоящий нос (+Z) направлен по касательной.
Он использует настоящий Fly-клип, зелёное свечение `#58ff76` и тот же
объёмный ореол `softMist`, что и светлячки в игре, закреплённый на брюшке.

Исходник сцены: `scripts/menu-backdrop-recording.ts`. Он переиспользует
`createMountains`, `createBroadleafTree`, `Watermill`, `SkyTrail`, `makeBoat`,
`createWaterSurface`, `createMeadowPlantGeometry`, материалы земли/травы/кустов,
`kirby-animated.glb`, игровую палитру и `firefly-animated.glb`.
Эти генераторы нужны только при записи и не входят в загрузку меню.

Перезапись из `kirby-game`:

```
npm run background:record
```

Нужны зависимости проекта и установленный Chrome. Другой исполняемый файл
можно задать через `BROWSER_EXECUTABLE`. Локальный Vite использует порт 5299.
Флаг `--poster-only` обновляет только заставку и координаты композиции.
Перед записью скрипт проверяет 72 позы: зазор между центральными Кирби,
направление настоящей головы относительно скорости, совпадение ореола
с брюшком, зелёный цвет и стык окружности. При замене готовых файлов нужно
обновить версию в трёх URL заставки/видео в `index.html` (сейчас `v=3`).

Выход: `public/backgrounds/meadow-menu.mp4` и `meadow-menu-poster.jpg`.
MP4 H.264, 1280×720, целевые 24 кадра/с и 1,1 Мбит/с, 12 секунд, без аудио;
заставка JPEG quality 78. В полёт, анимации Кирби, колесо мельницы, лодки и воду
заложено целое число периодов, чтобы переход при повторе был плавным.

Заставка предзагружается с высоким приоритетом и видна до скачивания видео.
`src/menu-backdrop.ts` запускает видео только за меню/индикатором загрузки,
останавливает в игре, скрытой вкладке и при reduced motion. При изначальном
reduced motion ролик вообще не запрашивается. Ошибка декодера или запрет
autoplay оставляют заставку. Дополнительного WebGL-контекста нет.
CSS размывает только фон; цвета карточек, текста и кнопок сохранены.

`scripts/menu-backdrop-browser.mjs` проверяет заставку при задержке видео,
размер/длительность, зацикливание, паузы, fallback, отсутствие игрового HUD
и минимум двух видимых Кирби вокруг настоящего меню на 1440 и 390 px.
Для этого `composition.json` хранит проекции центров реальных моделей.
`loading-browser.mjs` дополнительно проверяет ранний вход/сохранение,
ожидание подготовки мира, скрытый мир до входа и возврат к видеофону.
