## Воспроизведение версии 3

Генератор пробы — `arrange_soft.py`. Он использует извлечённые исходные
события/текстуры и артефакт версии 2 с её промежуточными стемами для сравнения
тембра. Основное усиление зафиксировано по версии 2; смягчение не компенсируется
автоматическим увеличением громкости всего микса. Генератор не устанавливает
пробу в игру.

```powershell
python arrange_soft.py --fluidsynth PATH_TO_FLUIDSYNTH --soundfont PATH_TO_SF2 --reference ORIGINAL_CACHE_DIR --base REVISION_2_ARTIFACT_DIR --base-work REVISION_2_RENDER_CACHE_DIR --work RENDER_CACHE_DIR --output OUTPUT_DIR
```

## Воспроизведение основы версии 2

Генератор основы — `arrange_faithful.py`. `arrange.py`
сохраняет первую пробу и предоставляет общие функции WAV/MIDI/рендера;
сам по себе он не создаёт текущую версию.

`extract_original.cjs` исполняет нотную и звуковую логику только второго
трека в VM, останавливается до записи игрового WAV и не получает доступа
к функциям записи оригинального генератора. Сохраняет исходную партитуру,
уровни и два исходных стема исключительно в указанную папку промежуточных
файлов. По умолчанию актуальный генератор вызывает его сам:

```powershell
python arrange_faithful.py --fluidsynth PATH_TO_FLUIDSYNTH --soundfont PATH_TO_SF2 --node PATH_TO_NODE --reference ORIGINAL_CACHE_DIR --work RENDER_CACHE_DIR --output OUTPUT_DIR
```

`--reuse-reference` разрешает использовать уже извлечённые данные из
`--reference` без повторного запуска JS. Используйте его только с тем же
исходным `make-music.cjs`; контрольная сумма сохранена в отчёте.
Генератор создаёт артефакты и не устанавливает их в игру.

Банк и рендерер находятся в игнорируемом `.cache/meadow-acoustic/`.
Банк не включён в проект; копия лицензии — `GeneralUser-GS-LICENSE.txt`.
