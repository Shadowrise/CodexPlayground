# Гладкие собираемые звёзды

Общая модель `src/collectible-star.ts` используется для награды лабиринта,
вершины Небесной тропы и разноцветных звёзд финального звездопада.
После уточнения пользователя модель представляет собой одну непрерывную
гладкую форму с округлёнными краями и выпуклыми лицевой и обратной сторонами.
Материал — мягкое золото с небольшой общей картой шероховатости 128 × 128.

Ореол использует тот же `softMist` из `src/soft-mist.ts`, что и свечение
светлячков: объёмный эллипсоид с аналитической толщиной, глубиной и обычным
перекрытием предметами сцены. У собираемых звёзд больше нет Sprite-ореолов.
Дополнительные источники света и проходы рендера не создаются.

Все экземпляры используют одну геометрию звезды (2 600 треугольников),
общую геометрию ореола (180 треугольников) и материалы, кешируемые по цвету.
На одну падающую звезду приходится два вызова отрисовки вместо прежних пяти.
У наград лабиринта и Небесной тропы заметный жёлтый объёмный ореол;
декоративное кольцо вокруг награды тропы убрано.
Правила получения, очки, положение и радиус сбора наград, таймеры и сетевое состояние сохранены.

`scripts/collectible-stars-browser.mjs` проверяет модели с лица, сбоку,
сзади и ночью, перекрытие ореола, отсутствие Sprite/источников света,
пиковые 13 звёзд и одинаковый тест рендера до/после на 1280 × 900.
Число вызовов для самих звёзд: 65 → 26 (66 → 27 вместе с тестовой плоскостью).
В последнем GPU-синхронизированном замере медиана составила около 0,7 мс
для обоих вариантов; p90 — около 1,2 мс против прежних 0,9 мс.
Это измерение изолированных звёзд, а не сравнение FPS всей игры.
Сводные данные и исходный замер сохранены рядом со снимками.

Для запуска нужен Vite; адрес задаётся `GAME_URL` (по умолчанию порт 5187).
`STARS_BASELINE=1` сохраняет исходный замер до правки модели.
`STARS_GAME_QA=1` дополнительно открывает настоящую игру, проверяет сбор
в лабиринте, восстановление награды, награду тропы и финальный звездопад,
а также сохраняет дневной, ночной и мобильный ракурсы. Для снимков наград
направление звезды фиксируется, сохраняя её обычную игровую модель и материалы.
Временные снимки и отчёты — `node_modules/.cache/collectible-stars/`.

32 профильных теста прошли; `npm run build` прошёл. Геометрические тесты
проверяют замкнутую поверхность без разрывов, лицевую и обратную стороны,
переиспользование ресурсов и объёмный ореол.
