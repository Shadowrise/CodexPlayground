# Автоматическое звёздное убежище

Звезда автоматически загорается и раскрывает общий золотой купол сразу
после притяжения в плоскость игроков. Удар Q не нужен. Пять секунд
сохранены для подлёта к готовому укрытию; затем начинается притяжение планеты.
Метка, предлагавшая ударить звезду, больше не показывается.

Движение, защита, блеск персонажей, синие глаза, подробная планета,
раскол, немедленный удар звезды в лоб, секундное оглушение и отскок сохранены.
Сервер хранит время автоматической активации. Участие в ответе звезды
засчитывается игрокам внутри купола в момент столкновения планеты.

`tests.log` — 40/40 профильных проверок прибытия/защиты, шести ответов до победы,
GLB меча/плаща и реального серверного Worker без события атаки.
`build.log` — TypeScript/Vite, main-BVF00mSU.js.
`full-tests.log` — первый общий прогон: 889/890, старый тест вихря ожидал
отсутствие автоматического урона звезды. Сценарий обновлён на три ответа
звезды плюс три удара в окна вихря; весь профиль из 40 проверок прошёл повторно.
`server-typecheck.log`, `final-typecheck.log` — серверный и игровой tsc.
`browser-qa.log`, `report.json`, `screenshots/` и `stellar-refuge-in-game.webm`
проверяют настоящий /phase 4-3 и прохождение без нажатий Q.

Настройки и механика метеоритов в этой правке не менялись: пользователь
попросил сначала предложить варианты усложнения.
Повтор: `node --import tsx scripts/meta-knight-refuge-browser.mjs --video`.
