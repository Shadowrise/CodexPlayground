# Детализация притягиваемой планеты

Захваченная планета получает геометрию 160×104 вместо 64×40, настоящий
небольшой рельеф, мелкие береговые линии, биомы, горные гряды, зерно пород,
снежные участки, облачные нити и отражение на океане. Детальность плавно
усиливается при приближении; дополнительные детали вычисляются процедурно.

Раскол больше не повторяет треугольную сетку икосаэдра. Сферическое
разбиение Вороного создаёт 140 неодинаковых кусков с общими извилистыми
ломаными границами. У каждого разная площадь и толщина; стенки проходят
через пять неровных слоёв, дно тоже имеет рельеф. Внешняя сторона сохраняет
подробную поверхность планеты, внутри видны каменные слои, минеральное
зерно, светлые вкрапления и затухающие раскалённые прожилки.
Один общий Mesh анимирует разлёт и вращение всех кусков на GPU.

Сохранены все предыдущие исправления: исчезновение луча к звезде,
блеск безопасности для всех участников, синие глаза, обхватывающие
планету разряды, немедленный полёт звезды от столкновения, удар в лоб,
одна секунда оглушения и плавный отскок по дуге.

`screenshots/`, `all-stages.png`, `stellar-refuge-in-game.webm` — новые
игровые кадры и непрерывная запись со звуком. `report.json`, `browser-qa.log`
проверяют механику, показ защитного блеска, цвет глаз и отсутствие ошибок.
`tests.log` проверяет также отсутствие разрывов в каждом объёмном куске,
разные размеры и конечные координаты рельефа; `full-tests.log` — 890/890.
