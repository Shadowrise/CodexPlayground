# Метеориты · больше огня

По замечанию пользователя усилен огонь: 28 отдельных языков вокруг камня,
64 огненных объёма в хвосте, живая огненная оболочка вместо слабой носовой
вспышки, ярче оранжево-золотое пламя и отражённый на окружении свет.
Хвост хранит 540 мс настоящей дуги вместо 320 мс, каждый сегмент ориентирован
по своему участку полёта. Обугленная поверхность и раскалённые трещины
остаются видны. Механика и размеры твёрдого камня прежние.

Синие «кубики» в начале прежней записи — 22 голубые частицы эффекта
попадания из MetaKnightBattleView, а не метеорит. QA возвращал часы назад,
но предыдущий burstAt сохранялся: отрицательный возраст проходил условие
age<700 и создавал ложное кольцо. Теперь возврат часов/смена боя сбрасывают
эффект, дополнительно проверяется неотрицательный возраст.

- `screenshots/` и `all-stages.png` — обновлённые игровые кадры.
- `meteors-in-game.webm` — новое видео со звуком, два уклонения и отражение.
- `report.json`, `browser-qa.log` — реальные команды, Q, урон и проверка
  отсутствия старых голубых частиц на первых двух бросках (`ghostBursts`).
- `tests.log` — 14 проверок метеоритов и представления боя прошли.
- `build.log` — успешный TypeScript/Vite, main-vH78eSRG.js.

Повтор: `node --import tsx scripts/meta-knight-meteor-browser.mjs --video`.
Команды: `/phase 4-2` — метеориты, `/phase 4-1` — вихрь, `/phase 4` — взлёт.
Исходные звуки и предыдущая проверка 880 тестов сохранены в папке без `-v2`.

Финальный Chrome QA прошёл: ghostBursts=0, JS/WebGL0. В новом видео два
уклонения и отражение третьего камня, игрок5/5, HPбосса6→5, высота180.
Продолжительность12,94с, median13,3ms/p9513,4ms. Крупный план и обычный
ракурс просмотрены; первый бросок дополнительно извлечён из записи в
`first-throw-from-video.png`, звук проверен в `video-inspection.json`.
