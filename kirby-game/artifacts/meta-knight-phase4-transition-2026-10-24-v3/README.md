# Мета Кнайт — ползущее электричество и запись разрядов

Третья версия первого листа четвёртой фазы. Все кадры и видео сняты в игре.

## Электричество

Полностью заменён способ распространения разряда. 36 основных путей
ветвятся четырьмя боковыми ответвлениями каждый. Их координаты фиксируются
для конкретного боя. Кончики последовательно достраивают короткие участки;
уже пройденная часть остаётся на месте. По пути проходят ведущая вспышка
и два повторных импульса. След постепенно затухает, кончики искрят.
Траектории доходят до настоящей кромки арены радиусом 46 м, где дают
короткие всплески искр. Разные ветви доходят в разное время. Растущая
кольцевая поверхность удалена. В фазах 1–3 сохранены удлинённые разряды
от удара мечом из предыдущей версии.

Прежний конус заменён 24 неровными дугами от разных точек меча и 12
свободными дугами вокруг и над Кнайтом. У них разная высота, кривизна,
длина и положение концов; палитра по-прежнему золотая.

## Пробный звуковой набор

Найдены и использованы три источника с лицензией CC0-1.0:

- Brian MacIntosh / BMacZero — [запись небольшого генератора Тесла](https://opengameart.org/content/electricity-sound-effects-0).
- faxcorp — [Electricity Game Sound Pack](https://opengameart.org/content/electricity-game-sound-pack): заряд, треск, взрывной удар, набор энергии, тяга.
- Joseph SARDIN / LaSonotheque — [Tonnerre #1](https://lasonotheque.org/tonnerre-1-s2718.html): настоящий гром без дождя.

Обрезан тихий участок перед громом, расставлены отдельные электрические
щелчки, подогнаны высота тона, длительность и громкость. Пять эпизодов
сведены в stereo PCM WAV 44,1 кГц с плавными границами и запасом по пику.
Они уже используются игрой. При недоступности файла работает резервный
синтез; загрузка сэмпла сама не запускает звук после отмены.

[Заряд, 2,8 с](../../public/audio/meta-knight-cosmic/cosmic-charge.wav)

[Удар и разряд по земле, 1,9 с](../../public/audio/meta-knight-cosmic/cosmic-impact.wav)

[Весь переход отдельной звуковой дорожкой](transition-sound.wav)

Исходные записи, адреса, авторы и SHA-256 сохранены в `audio-sources/`.
Кредиты поставляемых файлов: `public/audio/meta-knight-cosmic/CREDITS.md`.
Для пересборки микса: `node scripts/prepare-meta-knight-cosmic-audio.mjs`
при запущенной локальной игре (адрес задаётся через `GAME_URL`).

## Проверка

20/20 профильных проверок прошли, включая неподвижность уже пройденного
участка, постепенное появление новых ветвей, достижение настоящего края,
длительности/стерео/пики записей и 366 поз GLB с непрерывными стыками.
Production build / TypeScript прошли: `main-Bw4loLvx.js`.

Браузер проверил полный переход, загрузку пяти звуков, команду `/phase 4`,
фиксированную общую высоту, движение, портретный экран, сброс и отмену.
На кадрах WebGL error = 0; ошибок JavaScript нет. Видео: 1277 обновлений
за 17 с, median 13,3 мс, p95 13,5 мс в этой локальной проверке.
Числа сохранены в `report.json`, результат сведения — в `audio-mix-report.json`.
Отдельная браузерная проверка `meta-knight-cosmic-audio-browser.mjs`
подтвердила пики пяти настоящих записей на звуковом bus, остановку при
отмене и работу резерва при HTTP 404; `audio-browser-report.json`.
