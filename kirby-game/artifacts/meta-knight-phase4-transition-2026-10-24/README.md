# Мета Кнайт — переход в четвёртую фазу

Реальные кадры локальной игры. Реализован только первый лист утверждённой
раскадровки. После подъёма игра остаётся в постоянном полёте без атак
следующих подфаз. Кнайт получает шесть единиц здоровья.

В одиночной дуэли ввести `/phase 4`. Можно повторно ввести команду, чтобы
пересмотреть переход. `/phase 1`, `/phase 2`, `/phase 3` возвращают к обычным
фазам; отмена дуэли возвращает персонажа на поверхность арены.

Снимки сделаны проверочным скриптом в настоящей сцене и не дорисовывались.
Общий лист только размещает десять последовательных снимков рядом.
Видеозапись содержит настоящие анимации и стереозвуки эффектов; музыкальная
дорожка игры в отдельную запись эффектов не входит.

`report.json` содержит время каждого снимка, высоту босса и игрока,
положение клинка в кадре, WebGL-статус, проверку движения/сброса и параметры
видеозаписи. На всех снимках перехода WebGL error = 0, ошибок JavaScript нет.
Проверено движение с зажатым прыжком: высота остаётся 180 м. Проверены
переключение обратно на фазу 2 и отмена во время взлёта.

Автоматические проверки: полный набор 855/855; отдельная проверка реального
GLB проходит 366 поз и стыки между этапами: клинок не входит в корпус,
поддерживающая рука остаётся на рукояти. Авторитетный сервер сохраняет фазу
после пробуждения и фиксирует высоту участника, не поднимая наблюдателя.

Воспроизведение: запустить `npm run dev -- --port 5198` в `kirby-game`,
затем `node --import tsx scripts/meta-knight-cosmic-browser.mjs --video`.
